# 健身塑形控制台 · GitHub Pages 静态版

减脂塑身计划管理：30 天计划生成、动态阶段性效果预测（AI）、饮食与运动库管理、健康记录追踪。

## 使用说明

- **登录**：内置账号 `jlb` / `whx`（密码见管理员）
- **AI 功能**：GitHub Pages 无后端，需在「设置 → AI 助手」中**手动填写 DeepSeek API Key**（本地混淆加密存储）；未配置时自动降级本地引擎
- **数据**：保存在**当前设备的浏览器 localStorage**（每台设备相互独立，不跨设备同步）
- 完整版（多设备云同步 + 服务端 AI Key 分发）需运行本地 `server.js`，见主项目

## 本地开发版

单文件应用：`index.html` 无任何构建步骤，直接打开或任意静态托管即可。
